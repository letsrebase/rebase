tech-lexicon.json is vendored verbatim from letsrebase/rebase-verify (share/tech-lexicon.json at
commit 6a9943a90f7ccb93c2f5da121f724943fdecfd8f, when the repository was still called
letsrebase/work-profile), rebase's fork of Play-New/apply-new. The
lexicon, and groundedness.py, which ports src/groundedness.mjs, are Play New's work under the MIT
licence in LICENSE-apply-new (Copyright (c) 2026 Cosmico Srl - Play New).

To refresh it: copy share/tech-lexicon.json from the fork over tech-lexicon.json, update the commit
above, and run `uv run pytest projects/hub/packages/core/tests/test_work_profile_groundedness.py`.
The fork's `npm run lexicon` regenerates it from its label maps; if groundedness.mjs changed, port
the change to groundedness.py and the test vectors with it.

tech-labels.json is the output of labelVocabulary() in the fork's src/digest.mjs at commit
8914d0b0395af77371251107883f3425c14f2b92, sorted: every technology label the stack detection can
emit, which is what a name in techUsage must be (tech_usage.py). It is a second file because the
lexicon above holds tokens, with generic words dropped, and cannot say whether «Go» or «Shell» is a
label. To refresh it, run the command in its own $comment in the fork, paste the list in, update the
commit above, and run `uv run pytest projects/hub/packages/core/tests/test_work_profile_tech_usage.py`,
which also checks that every label's words are in the lexicon.
