What it reads

Seven lenses, from your logs.

1

What you work on

Three to five fields of work, counted, never named.

2

How you reason

Research-first, orchestrator, verification-heavy, risk-calibrated.

3

How you use the model

From directing it to thinking with it, and when you switch.

4

How deep it goes

Active days, sessions a day, session depth, streaks.

5

How you spread it

Steering a portfolio, or building one thing for months.

6

How long, per tech

Occasional, recurring, continuous: a label for month counts.

7

Agentic fluency

What you use, what you build (skills, hooks, CLAUDE.md), how you organise.

+

And a check

Three to five projects, your trajectory, and prose that must track the data.

How the work is done

Not what you say you do. What you actually do.

Counted by code · 7

  • Checks before every commit
  • Tests changed with the code
  • Failure reproduced before the fix
  • A plan before the first edit
  • The diff reviewed before commit
  • Design documents written
  • Security checks run

Classified by your model · 4

  • Asks for alternatives
  • Pushes back, with a reason
  • States when it's done
  • Limits the scope
